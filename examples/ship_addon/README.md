# 標準艦の見本

[English](README.en.md) · 日本語版が正です。 [制作の入口](../../docs/addon_development.md) / [詳しい手順](../../docs/ship_addon_data.md)

対象: ShinColle-kai 1.20.1-0.13.0、Minecraft 1.20.1 / Forge（開発環境: Forge 47.4.0、Java 17）。
Java・追加 MOD は不要です。本体に入っている鹿島のモデル・画像・アニメーションを参照します。
別の艦 ID `shincolle_example:training_ship` として追加され、鹿島を上書きしません。

## 入れ方

この `ship_addon` フォルダはデータパックとリソースパックを兼ねます。

1. サーバー（シングルプレイならそのワールド）の `datapacks/` にフォルダごとコピーします。
2. 各クライアントの `resourcepacks/` に同じフォルダをコピーし、リソースパック画面で有効にします。
3. ワールドを開くか、管理者として `/reload` を実行します。`/datapack list enabled` で読み込みを確認します。

ZIP にするなら `pack.mcmeta`・`data/`・`assets/` を ZIP の直下に置きます。外側のフォルダを重ねないでください。
専用サーバーはデータ側だけを使い、画像をクライアントへ自動配布しません。

## 出し方

チート／管理者権限のあるプレイヤーが実行します。

```mcfunction
/give @s shincolle_kai:generic_ship_spawn_egg{ShipId:"shincolle_example:training_ship",Hostile:0b} 1
```

卵を持ってブロックの面を右クリックすると、使ったプレイヤーの味方艦として出てきます。
普段の遊びでは、小型・大型の建造で手に入ります。この見本だけを入れた場合、素材に関係なく、建造のたびに 5% の確率で出ます（`weight: 500`）。
他の weighted 定義との合計が 50% を超えると、比例して縮められます。野生の湧きは無効にしてあります。

確認用に敵個体の卵が必要なら、同じコマンドの `Hostile:0b` を `Hostile:1b` に変えます。
`/summon` は卵と違って所有者や初期の補給を設定しないので、味方艦の動きを確かめるときは卵を使ってください。

## 自分の艦へ変える

最初にコピーのままで導入し、それから [ID の付け替えと制作手順](../../docs/ship_addon_data.md#2-コピーしてから変更する) に進んでください。
JSON の変更はサーバーの `/reload`、見た目の変更はクライアントのリソース再読み込み（F3+T）で反映します。
ワールドのバックアップ後、保存・終了・再起動して同じ ID が残ることも確認してください。
